AFK Bot v3 setup

1. Install

npm install

Copy .env.example to .env, set a strong dashboard password and session secret, then edit settings.json.

2. Run

npm start

Open your deployment URL and log in. Configure the Minecraft server under settings.json → server.

3. Deploy

Railway and Render: deploy from GitHub, set environment variables, use npm start, and mount persistent storage for data/bot.sqlite. GitHub Actions is for CI/syntax checks, not reliable 24/7 hosting; scheduled runners are temporary and may stop.

Security

Do not expose this dashboard publicly without a strong password and HTTPS. Never commit .env or bot credentials.
